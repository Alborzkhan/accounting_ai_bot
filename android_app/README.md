# اپلیکیشن اندروید نارین

یک اپ اندرویدی ساده که همان وب‌اپ نارین (`web_app/`) را به‌صورت بومی روی گوشی باز می‌کند - بدون محدودیت‌های Mini App تلگرام/بله (مثل مجوز میکروفون یا صفحه‌ی هشدار تونل).

## این پروژه روی این سرور قابل Build نیست

این ماشین فقط JRE 1.8 دارد (نه JDK) و پوشه‌ی Android SDK خالی است (بدون platforms/build-tools). برای Build واقعی APK باید این پروژه را روی ماشینی با **Android Studio** نصب‌شده باز کنید؛ Android Studio خودش JDK و SDK لازم را مدیریت/دانلود می‌کند.

## مراحل Build

1. پوشه‌ی `android_app` را در Android Studio باز کنید (File → Open).
2. صبر کنید تا Gradle sync کامل شود (بار اول کمی طول می‌کشد).
3. مقدار `app_base_url` در [app/src/main/res/values/strings.xml](app/src/main/res/values/strings.xml) را به آدرس فعلی سرور (تونل تست یا دامنه‌ی واقعی) به‌روزرسانی کنید.
4. روی Run بزنید تا روی گوشی/شبیه‌ساز نصب شود، یا از منوی Build → Generate Signed Bundle/APK برای ساخت فایل APK نهایی استفاده کنید.

## نکته‌ی مهم درباره‌ی آدرس سرور

چون فعلاً از یک تونل تست (نه دامنه‌ی دائمی) استفاده می‌شود، هر بار که آدرس عوض شود باید `app_base_url` به‌روزرسانی و اپ دوباره Build شود. وقتی پروژه روی یک سرور واقعی با دامنه‌ی ثابت مستقر شد، این مقدار فقط یک‌بار تنظیم می‌شود و دیگر لازم نیست تغییر کند.

## امکانات پیاده‌سازی‌شده

- مجوز میکروفون برای فرمان صوتی (با تأیید WebView)
- آپلود فایل (لوگو) از طریق `<input type="file">`
- دانلود PDF فاکتور از طریق DownloadManager اندروید (در پوشه‌ی Downloads ذخیره می‌شود)
- دکمه‌ی برگشت اندروید = برگشت در تاریخچه‌ی صفحه (نه بستن اپ)
- صفحه‌ی خطای اتصال با دکمه‌ی تلاش دوباره، اگر سرور در دسترس نباشد
